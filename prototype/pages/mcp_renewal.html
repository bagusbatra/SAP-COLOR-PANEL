Renewal MCP
Halaman khusus untuk memperbarui MCP yang expired atau menjelang expired. Sales harus siapkan SO baru dulu dengan material color yang sudah punya Color Code. Sistem akan otomatis membuat MCP baru dan meng-obsolete MCP lama.

Input SO Renewal

SO yang materialnya sudah punya Color Code (Renewal). Untuk material baru → gunakan Request DCP.

Kandidat Renewal

Pilih SO dulu
Sistem akan tampilkan MCP mana yang bisa di-renewal.
