Semua objek: Warning % = 10,0  dan  Buffering = TIDAK AKTIF.

Catatan: field "Number length domain" di SNRO minta nama domain, bukan angka.
Panjang nomor diambil dari panjang domain yang ditunjuk. NUM4/NUM5/NUM9/NUM12
adalah domain bawaan SAP dan sudah diverifikasi ada di sistem ini. F4 di field
tersebut tidak menyediakan input help, jadi nama domain harus diketik langsung.

Catatan: buffering sengaja dimatikan. Number range buffering membuat tiap server
aplikasi mengambil jatah nomor di muka, akibatnya nomor bolong dan tidak urut.
Color Code dan DCP ID tercetak di dokumen dan panel fisik, jadi keterurutan lebih
berharga daripada sedikit tambahan kecepatan.

Catatan: To-Year Flag YES berarti pemanggilan NUMBER_GET_NEXT wajib mengisi
parameter TOYEAR, dan penomoran mulai dari 0001 lagi tiap tahun.

PERINGATAN OPERASIONAL - interval per tahun untuk ZCP_REQ dan ZCP_DCP:
  Interval yang dibuat sekarang hanya berlaku untuk tahun 2026. Per 1 Januari
  2027 pembuatan Request dan DCP baru akan gagal dengan interval_not_found
  sampai ada yang membuat interval tahun 2027 di SNRO. Jadikan tugas rutin
  akhir tahun, atau buat interval tahun berikutnya lebih awal.

PERINGATAN TRANSPORT:
  Objek number range ikut transport, INTERVALNYA TIDAK. Interval adalah data
  client, bukan objek repository. Waktu sistem dipindah ke QAS atau PRD,
  kelima interval di atas harus dibuat ulang secara manual di sistem tujuan.
  Ini penyebab paling umum aplikasi jalan mulus di DEV lalu langsung error
  di PRD.
