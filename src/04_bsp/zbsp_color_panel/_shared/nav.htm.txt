Potongan SIDEBAR bersama untuk aplikasi BSP ZBSP_COLOR_PANEL
============================================================

Disalin ke setiap halaman kecuali login.htm, tepat di dalam
<div class="flex"> sebagai anak pertama.

TAHAP 1: seluruh menu ditampilkan tanpa penyaringan role.
Penyembunyian per role masuk di Task 15, dengan bentuk:

  <% IF gv_role CS 'ADMIN' OR gv_role CS 'IT'. %>
    ... satu blok <a> ...
  <% ENDIF. %>

Peta role per menu untuk Task 15:
  Dashboard    : semua role
  Request DCP  : SALES, ADMIN, IT
  DCP          : ADMIN, QC, IT
  User         : IT saja

MENANDAI MENU AKTIF: pada halaman yang bersangkutan, ganti kelas
  class="flex items-center gap-3 px-5 py-2 text-sm text-gray-300 hover:bg-navy hover:text-white"
menjadi
  class="flex items-center gap-3 px-5 py-2 text-sm bg-navy text-white"

ATURAN: nol karakter non-ASCII. Atribut class dalam string JavaScript
harus satu baris, jangan dipecah antar baris.
